# budget

The account-wide $1 monthly COST Budget `qmc-monthly` with three notifications (ACTUAL > 1%, ACTUAL > 100%, FORECASTED > 100%) to the alerts topic only: direct email subscribers need AWS User Notifications verification, which the new-AWS-experience SCP denies (the topic's email subscription delivers them). The root creates it only when `create_budget` is true, because budgets are per account. HANDOFF §8.2.
